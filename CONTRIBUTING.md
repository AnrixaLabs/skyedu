# Contributing

Thank you for your interest in Sky Education tooling.

## Current contribution model

This repository is maintained by AnrixaLabs and is not currently operated as an open community project. External pull requests may be reviewed, but acceptance is not guaranteed.

Before proposing a substantial change, open a regular GitHub issue describing:

- the problem being solved;
- the affected component;
- the proposed approach;
- any compatibility or deployment impact.

## Development expectations

- Keep changes focused and reviewable.
- Do not commit generated output unless it is intentionally part of the source package.
- Do not commit real credentials, environment files, private keys, machine-local configuration, or personal/student data.
- Preserve existing configuration through placeholders in `.env.example`.
- Document new environment variables and setup requirements.
- Include verification steps for behavior changes.

## Security issues

Do not report credentials or exploitable security problems in a public issue. Follow `SECURITY.md`.
